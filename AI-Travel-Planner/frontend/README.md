# Aagam's Frontend Workspace

This folder is intentionally a small integration starter, not the final UI.

Aagam can build the full React + TypeScript + Tailwind application here.

Required screens from the project design:

1. Landing/Home
2. Navigation/Auth
3. Trip Creation Form
4. Saved Trips Dashboard
5. Trip Detail Workspace
6. Day Tabs Navigation
7. Activity Cards List
8. AI Refinement Panel
9. Interactive Map Component

The backend API client is already provided in `src/api/client.ts`.

## Start

```powershell
npm install
npm run dev
```

Then connect the UI to:

```text
http://localhost:4000
```
